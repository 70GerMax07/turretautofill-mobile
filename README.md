# Turret Auto Fill (mobile)

**EN** - A client-side Mindustry mod for mobile. An on-screen button feeds nearby item turrets with ammo from your core, as if you carried it by hand. Works on any server (the server does not need the mod).

- Tap the button to toggle feeding; long-press it to open settings (also available in Settings -> Turret Auto Fill).
- Per-turret ammo priority (order + on/off toggle per ammo type).
- Movable and resizable button.
- Languages: English / Russian (switch inside the settings).

**RU** - Клиентский мод для мобильного Mindustry. Кнопка на экране заправляет ближайшие турели патронами из ядра, как если бы вы носили их вручную. Работает на любых серверах (серверу мод не нужен).

- Нажатие на кнопку - вкл/выкл подачу; долгое нажатие - настройки (также в Настройки -> Turret Auto Fill).
- Приоритет патронов для каждой турели (порядок + вкл/выкл).
- Кнопку можно двигать и менять её размер.
- Языки: English / Русский (переключается в настройках).
